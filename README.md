# 🛍️ Shopping Store

Aplicación de consola en Java que simula una tarjeta de crédito para registrar compras. El usuario define un límite inicial, realiza compras con una descripción y visualiza el saldo restante y el historial de compras.


## 🚀 Características

- Definición de límite inicial de tarjeta.
- Registro de múltiples compras con validación de saldo.
- Visualización de la lista de compras.
- Muestra del saldo restante al finalizar las compras.
- Ordenamiento opcional de compras por valor.
